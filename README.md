# TrainerHRMS

A responsive HRMS dashboard inspired by a modern employee check-in workflow.

## Features
- Work / Remote Work / College Session / Travel status
- Check-in, check-out and live work timer
- Break timer
- Monthly attendance summary
- Notifications
- Leave application modal
- EOD (End of Day) report form
- Attendance report table
- CSV export
- Light / dark mode
- Responsive mobile layout

## Tech
HTML, CSS and vanilla JavaScript. No backend or database is required for the demo.

## Run
Open `index.html` in a browser.

## Next production steps
Connect the UI to Node.js/Express REST APIs and MongoDB/MySQL for authentication, attendance persistence, leave approval and admin reporting.
